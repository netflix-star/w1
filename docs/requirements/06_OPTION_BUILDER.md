# Option Builder

## Option Types
- Material variant
- Mesh/geometry variant
- Visibility option
- Transform option where explicitly supported
- Package
- Feature toggle

## Option Data
ID, name, description, thumbnail, group, target components, implementation type, price, dependencies, exclusions, default state.

## No-Code Requirement
Creators must be able to add and edit options without changing application source code.

## Preview
Every option must be previewable in the actual 3D viewport before publishing.
