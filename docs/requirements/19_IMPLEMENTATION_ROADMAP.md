# Implementation Roadmap

## Phase 0 — Foundation
Repository, design system, auth, tenant/workspace model, database, object storage, CDN and CI/CD.

## Phase 1 — GLB Pipeline
Upload, validation, parsing, scene analysis, optimization and runtime delivery.

## Phase 2 — Authoring Studio
3D viewport, scene tree, inspector, component mapping, material editor and option builder.

## Phase 3 — Configuration Engine
Option groups, compatibility rules, deterministic configuration serialization and pricing.

## Phase 4 — Studio
HDRI, lights, camera, floor, reflections and capture.

## Phase 5 — Publishing
Validation, immutable releases, public runtime, share URL and embed.

## Phase 6 — Export
Configuration JSON, image export and configured GLB export.

## Phase 7 — Hardening
Performance, security, monitoring, QA, browser/device matrix and rollback.

## Phase 8 — Scale
Team collaboration, analytics, white-labeling, custom domains, CMS and advanced rendering.
