# Model Inspector

## Scene Tree
Show nodes, hierarchy, meshes, materials, cameras, lights and animations.

## Inspector
For a selected item show stable ID, source name, type, transform, visibility, mesh statistics and material assignments.

## Semantic Mapping
Allow mapping to roles such as body, wheel, brake, glass, seat, dashboard, trim, accessory and custom component.

## Bulk Operations
Support multi-selection, bulk mapping and search.

## Principle
Authoring metadata is stored in the project model; source GLB is not destructively modified.
