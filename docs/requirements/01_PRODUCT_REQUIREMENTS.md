# Product Requirements

## Creator Workflow
Create project → import GLB → validate → inspect → map components → create material/geometry options → define rules → configure pricing → configure studio → customize UI/branding → preview → validate → publish → share/embed/export.

## Customer Workflow
Open URL → load optimized runtime → select options → see immediate 3D changes → review configuration → optional price → save/share/capture.

## Required Modules
- Project management
- GLB/GLTF import
- Asset validation
- Model inspector
- Component mapper
- Material editor
- Option builder
- Compatibility/rule engine
- Configuration runtime
- PBR/studio renderer
- Camera/environment system
- Pricing
- Publishing
- Share URLs
- Embed
- JSON/image/GLB export
- User/team permissions
- Analytics

## Acceptance
Every visible control must have a real underlying state and behavior, survive save/reload where applicable, and work in preview/published runtime where intended.
