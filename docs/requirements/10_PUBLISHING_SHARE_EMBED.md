# Publishing, Share & Embed

## Publish
Draft → validate → build runtime manifest → freeze release → optimize/deploy assets → publish URL.

## Validation Gate
Block publication for missing assets, broken references, invalid options/rules, unsupported dependencies or unresolved configuration errors.

## Share
Public URL must resolve to an immutable release and reproduce the same experience on another browser/device.

## Embed
Generate a secure iframe/embed configuration with optional branding, initial configuration and allowed options.

## Release Management
Support publish, unpublish and republish as versioned releases. Do not mutate an already published release.
