# Studio Rendering Specification

## Rendering
PBR materials, HDR environments, correct color management, tone mapping, shadows, contact shadows where supported, reflections, anti-aliasing and controlled post-processing.

## Lighting
Area, spot and directional lights with intensity, color/temperature, position, rotation and size controls.

## Environments
Versioned HDRI presets with rotation, intensity, background and reflection settings.

## Camera
Presets plus orbit, pan, zoom, focal length/FOV, exposure, aperture, focus distance and depth of field.

## Studio Presets
Automotive dark, white cyclorama, softbox, showroom, dramatic, outdoor day, sunset and night.

A control is implemented only if it changes the real renderer and is represented in saved project state.
