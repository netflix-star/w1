# 3D Configurator Platform — Project Bible

## Product
A production-ready browser platform for importing GLB/GLTF assets, inspecting and mapping them, creating configuration options, configuring PBR/studio rendering, publishing shareable experiences, embedding them, and exporting configurations/assets.

**Core workflow:** Import → Author → Configure → Studio → Publish → Share → Export

## Two Experiences
### Authoring Studio
Import GLB, validate, inspect scene, map components, create materials/options/rules, configure studio, preview, validate, publish and export.

### Published Experience
Fast customer-facing runtime with real 3D configuration, PBR materials, responsive UI, optional pricing, save/share/capture and no developer intervention.

## Non-Negotiables
- Data-driven configuration.
- Real PBR rendering.
- Real persistence.
- Real publishing and share URLs.
- Versioned releases.
- Secure multi-tenant access.
- No fake controls.
- No customer-specific source-code hacks.
- Imported assets must be validated rather than silently accepted.

## Production Success Test
A non-developer uploads a properly prepared GLB, maps it, creates options, publishes it and shares a working URL without modifying application source code.
