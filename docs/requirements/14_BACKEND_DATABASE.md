# Backend and Database

## Core Tables
tenants, workspaces, users, memberships, projects, project_versions, assets, asset_versions, node_mappings, materials, material_variants, option_groups, options, compatibility_rules, environments, lighting_presets, camera_presets, releases, configurations, export_jobs, analytics_events.

## Requirements
PostgreSQL, migrations, foreign keys, indexes, unique constraints and transactional writes.

## API Security
Authentication, authorization, schema validation, rate limiting, secure uploads, strict CORS and safe error handling.

## Pricing
Authoritative pricing must be validated/calculated server-side.
